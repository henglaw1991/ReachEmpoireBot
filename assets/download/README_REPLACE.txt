ReachEmpireBot Mobile Sign Up / Log In Standard

Replace the included HTML files in the website root.

Mobile standard:
- Sign Up and Log In are exactly equal width.
- Both buttons use the same 42px height.
- 8px gap between buttons.
- Button group uses the full mobile content width with 14px side margins.
- Maximum group width: 430px.
- Sign Up keeps orange primary style.
- Log In keeps dark outline secondary style.
- Desktop layout is not changed.

This standard matches the Home Page mobile button sizing more closely and applies it consistently to the other pages.
